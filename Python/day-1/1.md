# What is Python?

Python is a programming language used for:

* AI & Machine Learning
* Web Development
* Automation
* Data Science
* Cyber Security

Example:

```python
print("Hello World")
```

Output:

```
Hello World
```

---

# print()

`print()` displays output on the screen.

Example:

```python
print("Hello Keerthi")
```

Output:

```
Hello Keerthi
```

---

# Variables

Variables are containers used to store data.

Example:

```python
name = "Keerthi"
```

Here:

* Variable Name → `name`
* Value → `"Keerthi"`

Print variable:

```python
name = "Keerthi"

print(name)
```

Output:

```
Keerthi
```

---

# Data Types

## 1. String (str)

Stores text.

```python
name = "Keerthi"
city = "Bangalore"
```

---

## 2. Integer (int)

Stores whole numbers.

```python
age = 23
year = 2025
```

---

## 3. Float (float)

Stores decimal numbers.

```python
height = 5.8
price = 99.99
```

---

## 4. Boolean (bool)

Stores True or False.

```python
is_logged_in = True
is_admin = False
```

---

# type()

Used to check data type.

Example:

```python
name = "Keerthi"

print(type(name))
```

Output:

```
<class 'str'>
```

---

# User Input

Take input from user.

Example:

```python
name = input("Enter your name: ")

print(name)
```

Input:

```

```

Output:

```

```
