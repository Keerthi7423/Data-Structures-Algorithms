DAY 32 — CONTAINS DUPLICATE

Problem: Contains Duplicate

==================================================

1. PROBLEM STATEMENT
   ==================================================

Given an integer array nums

Return:

true  → if any value appears more than once
false → if all values are unique

Example:

nums = [1,2,3,1]

Output:

true

Because:
1 appears twice

---

nums = [1,2,3,4]

Output:

false

No duplicates

==================================================
2. INTERVIEWER FIRST QUESTION
=============================

"What is your first approach?"

Answer:

Brute Force

Always start simple

==================================================
3. BRUTE FORCE ALGORITHM
========================

Compare every element with every other element

Example:

1 compare with 2
1 compare with 3
1 compare with 1

Duplicate found

==================================================
4. BRUTE FORCE CODE
===================

function containsDuplicate(nums) {
for (let i = 0; i < nums.length; i++) {
for (let j = i + 1; j < nums.length; j++) {
if (nums[i] === nums[j]) {
return true;
}
}
}

```
return false;
```

}

==================================================
5. BRUTE FORCE CODE EXPLANATION
===============================

Outer loop:
Pick first element

Inner loop:
Compare remaining elements

if condition:
Check duplicate

return true:
Duplicate found

return false:
No duplicates found

==================================================
6. BRUTE FORCE COMPLEXITY
=========================

Time Complexity:

O(n²)

Reason:
Nested loops

---

Space Complexity:

O(1)

Reason:
No extra memory used

==================================================
7. WHY BRUTE FORCE IS BAD?
==========================

For huge arrays:
Too many comparisons

Very slow

==================================================
8. BRUTE FORCE ALTERNATIVE → SORTING
====================================

Sort array first

Example:

[4,1,3,1]

After sorting:

[1,1,3,4]

Duplicates become adjacent

==================================================
9. SORTING CODE
===============

function containsDuplicate(nums) {
nums.sort((a, b) => a - b);

```
for (let i = 1; i < nums.length; i++) {
    if (nums[i] === nums[i - 1]) {
        return true;
    }
}

return false;
```

}

==================================================
10. SORTING COMPLEXITY
======================

O(n log n)

Reason:
Sorting takes time

O(1)

(Depends on implementation)

11. NEW CONCEPT → HASHSET
=========================

HashSet stores only unique values

Duplicate values are ignored

Example:

let set = new Set()

set.add(1)
set.add(2)
set.add(1)

Final:

{1,2}

==================================================
12. HASHSET OPERATIONS
======================

Add value:

set.add(value)

---

Check value:

set.has(value)

---

Delete value:

set.delete(value)

==================================================
13. WHY HASHSET HERE?
=====================

Problem asks:

Find duplicates quickly

HashSet gives fast lookup

O(1)

15. BEST OPTIMIZED SOLUTION
===========================

function containsDuplicate(nums) {
let seen = new Set();

```
for (let num of nums) {
    if (seen.has(num)) {
        return true;
    }

    seen.add(num);
}

return false;
```

}

==================================================

==============================

Step 1:

Step 2:
Loop array

Check duplicate

Add current number

Return false if no duplicate found
