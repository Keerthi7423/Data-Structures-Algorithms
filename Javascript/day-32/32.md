1. PROBLEM STATEMENT
   ==================================================

Given an integer array nums

Return:

true → if any value appears more than once
false → if all values are unique

---

Example 1:

nums = [1,2,3,1]

Output:

true

Because:
1 repeats

---

Example 2:

nums = [1,2,3,4]

Output:

false

All values are unique

5. BRUTE FORCE CODE
===================

function containsDuplicate(nums) {
for (let i = 0; i < nums.length; i++) {
for (let j = i + 1; j < nums.length; j++) {
if (nums[i] === nums[j]) {
return true;
}
}
}

```
return false;
```

}

11. NEW CONCEPT → HASHSET
=========================

HashSet stores only unique values

Duplicate values are automatically ignored

---

Example:

let set = new Set()

set.add(1)
set.add(2)
set.add(1)

Final:

{1,2}

15. BEST OPTIMIZED SOLUTION
===========================

function containsDuplicate(nums) {
let seen = new Set();

```
for (let num of nums) {
    if (seen.has(num)) {
        return true;
    }

    seen.add(num);
}

return false;
```

}
