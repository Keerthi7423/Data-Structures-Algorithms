LeetCode #349
Difficulty: Easy

==================================================

1. PROBLEM STATEMENT
   ==================================================

Given two arrays:

nums1
nums2

Return common elements present in both arrays.

Each element should appear only once.

---

Example:

nums1 = [1,2,2,1]

nums2 = [2,2]

Output:

[2]

Add to result

==================================================
4. BRUTE FORCE CODE
===================

function intersection(nums1, nums2) {
let result = [];

```
for (let i = 0; i < nums1.length; i++) {
    for (let j = 0; j < nums2.length; j++) {
        if (
            nums1[i] === nums2[j] &&
            !result.includes(nums1[i])
        ) {
            result.push(nums1[i]);
        }
    }
}

return result;
```

}

==================================================
10. OPTIMIZED LOGIC
===================

Convert nums1 into Set

Loop nums2

If element exists:

Add to result set

Return final array

==================================================
11. OPTIMIZED CODE
==================

function intersection(nums1, nums2) {
let set1 = new Set(nums1);
let result = new Set();

```
for (let num of nums2) {
    if (set1.has(num)) {
        result.add(num);
    }
}

return [...result];
```

}
