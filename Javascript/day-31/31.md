==================================================
2) WHAT IS TIME COMPLEXITY?
===========================

Time complexity = how fast/slow your code becomes when input size grows.

Example:

Array size = 5
Loop runs 5 times

Array size = 100
Loop runs 100 times

Used to measure speed.

==================================================
O(1) → CONSTANT TIME
====================

let arr = [10,20,30]
console.log(arr[0])

Only one operation.

Even if array has 1 million elements:
still one operation.

Very fast

==================================================
O(n) → LINEAR TIME
==================

for(let i=0;i<arr.length;i++){
console.log(arr[i])
}

If n = 5 → 5 operations
If n = 100 → 100 operations

Grows linearly

==================================================
O(n²) → NESTED LOOP
===================

for(let i=0;i<n;i++){
for(let j=0;j<n;j++){
console.log(i,j)
}
}

If n = 5 → 25 operations
If n = 100 → 10,000 operations

Very slow

4) PROBLEM — TWO SUM
====================

Problem: Two Sum

Given:

nums = [2,7,11,15]
target = 9

Find indices whose sum = target

Output:

[0,1]

Because:

2 + 7 = 9

==================================================
5) BRUTE FORCE ALGORITHM
========================

Idea:

Check every possible pair.

Example:

2 with 7
2 with 11
2 with 15
7 with 11
7 with 15

==================================================
BRUTE FORCE CODE
================

function twoSum(nums,target){

for(let i=0;i<nums.length;i++){

```
  for(let j=i+1;j<nums.length;j++){

     if(nums[i]+nums[j]===target){
        return [i,j]
     }

  }
```

}
}

==================================================
BRUTE FORCE EXPLANATION
=======================

Outer loop:
Picks first number

Inner loop:
Checks remaining numbers

if condition:
Checks sum

return:
Returns indices

==================================================
BRUTE FORCE COMPLEXITY
======================

Time Complexity:

O(n²)

Why?

Nested loops

---

Space Complexity:

O(1)

Why?

No extra memory used

==================================================
WHY BRUTE FORCE IS BAD?
=======================

For huge arrays:

Very slow

7) WHAT IS HASHMAP?
===================

Stores data as key-value pairs

Example:

{
2:0,
7:1
}

Format:

number : index

Fast lookup

==================================================
8) COMPLEMENT CONCEPT
=====================

Target = 9

Current number = 2

Need:

9 - 2 = 7

That needed number is called:

Complement

==================================================
9) OPTIMIZED CODE
=================

function twoSum(nums,target){

let map={}

for(let i=0;i<nums.length;i++){

```
  let complement = target - nums[i]

  if(map[complement] !== undefined){
     return [map[complement], i]
  }

  map[nums[i]] = i
```

}
}

==================================================
OPTIMIZED CODE EXPLANATION
==========================

Step 1:
Create hashmap

Step 2:
Loop through array

Step 3:
Find complement

Step 4:
Check hashmap

Step 5:
Return answer

==================================================
OPTIMIZED COMPLEXITY
====================

Time Complexity:

O(n)

Why?

Only one loop

---

Space Complexity:

O(n)

Why?

Extra hashmap storage used
