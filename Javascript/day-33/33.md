   ==================================================

Given two strings:

true → if t is an anagram of s

---

What is an Anagram?

Two strings must have:

* Same characters
* Same frequency of characters

---

Example 1:

s = "anagram"
t = "nagaram"

Output:

true

---

Example 2:

false

12. BEST OPTIMIZED SOLUTION
===========================

function isAnagram(s, t) {
if (s.length !== t.length) {
return false;
}

```
let count = {};

for (let char of s) {
    count[char] = (count[char] || 0) + 1;
}

for (let char of t) {
    if (!count[char]) {
        return false;
    }

    count[char]--;
}

return true;
```

}
