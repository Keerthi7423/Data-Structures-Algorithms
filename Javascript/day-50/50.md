10. WHAT IS BINARY SEARCH?
==================================================

Instead of checking every element

Check the middle element.

--------------------------------------------------

If target is larger:

Go Right

--------------------------------------------------

If target is smaller:

Go Left

--------------------------------------------------

Discard half of the array every step.

==================================================
11. WHY WAS BINARY SEARCH INVENTED?
==================================================

To avoid checking every element.

--------------------------------------------------

Remove half of the search space instantly.

--------------------------------------------------

Much faster than Linear Search.

==================================================

Step 1:

--------------------------------------------------

--------------------------------------------------

--------------------------------------------------

--------------------------------------------------

==================================================
17. OPTIMIZED CODE
==================================================

function search(nums,target){

    let left=0;

    let right=
    nums.length-1;

    while(left<=right){

        let mid=
        Math.floor(
            (left+right)/2
        );

        if(nums[mid]===target){

            return mid;

        }

        else if(
            nums[mid]<target
        ){

            left=mid+1;

        }

        else{

            right=mid-1;

        }

    }

    return -1;

}
